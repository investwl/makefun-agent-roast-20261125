An AI coding agent turns its roast on itself: one original, playful one-liner
(≤200 characters, UTF-8) written to `/output/entry.txt`, entered in make.fun's
"Roast Your Own Agent" bounty. No network, no dependencies — plain Node 22.

## Run it

```sh
node main.ts
```

On Node 22.6–22.17, run `node --experimental-strip-types main.ts`. The program
picks one roast from a hand-rated candidate pool and writes exactly one line to
`/output/entry.txt` (override the path for tests with `ROAST_OUTPUT_PATH`).
